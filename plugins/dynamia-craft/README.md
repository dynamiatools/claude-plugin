# dynamia-craft

Small skills that make Claude work in an orderly way. No hooks, no commands, nothing loaded unless a skill is used.
Ideas adapted from [obra/superpowers](https://github.com/obra/superpowers) (MIT), trimmed to what we use.

| Skill | Use it to |
|---|---|
| `brainstorming` | Ask what is missing before building something non-trivial |
| `debugging` | Find the root cause before proposing a fix |
| `plans` | Turn a clear spec into small steps, each with a check |
| `review-feedback` | Verify review comments before implementing them |
| `tdd` | Test first, watch it fail (opt-in) |
| `clear-answers` | Short, direct answers and reports |

Install: add the marketplace and enable `dynamia-craft` next to `dynamia`.
