# Landing patterns

Common spine: **hero** (what it is, for whom, the benefit, one primary action, a visual) → **proof** (logos, numbers, testimonials, only real ones) → **how it works** (3 steps) → **benefits or features** (outcome first) → **objections** (FAQ, security, pricing clarity) → **final call to action**.

| Product type | Order and emphasis |
|---|---|
| SaaS, B2B tool | hero with product screenshot → customer logos → problem and outcome → features by job → integrations → pricing → FAQ → CTA. Primary: "Start free" or "Book a demo", not both with equal weight |
| Developer tool or API | hero with code or install command → quickstart → features → docs links → pricing or open-source info → community. Show the real thing, not stock art |
| Mobile app | hero with phone screens and store badges → 3 key features → social proof and ratings (real) → screenshots → FAQ. Make the install action work on the visitor's OS |
| E-commerce product | hero with product images → price and buy → benefits → specs → reviews → shipping and returns → related. Trust and clarity above all |
| Service or agency | hero with the offer → services → process → case studies → team → contact form. One contact path |
| Event or webinar | hero with date, place, action to register → agenda → speakers → venue or link → registration. Countdown only if true |
| Pricing page | plans compared in one table, a recommended plan, billing toggle, what is included, FAQ, enterprise contact |
| Waitlist or pre-launch | promise → why now → one field form → what happens next. Collect the minimum |
| Nonprofit or cause | story and impact → how donations are used → donate (amounts, one-time and monthly) → proof and transparency |

## Rules
- Headline: the outcome for the visitor in plain words, readable in 5 seconds, matching the ad or link that led here. Subhead adds the how.
- One primary action per screen, repeated down the page. Button text says what happens ("Create my account").
- Proof near the claims it supports. Specific beats superlative.
- Above the fold on a 375 px phone: headline, subhead, the action. Test it.
- Forms: only the fields needed (`dynamia-ui:charts-forms`). Pricing: no hidden costs; say what the trial includes.
- Performance: hero image optimized and not lazy loaded; no layout shift; third-party scripts late (`dynamia-ui:perf-review`).
- Accessible: contrast, focus, alt text, motion off with reduced-motion. Legal links, privacy and cookie consent where required.
- Measure: one event per primary action so the page can be judged.
